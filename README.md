# Agent Up content library

This repository contains the content of [Agent Up](https://aai-institute.github.io/frontier-ai-academy/), the agent-native learning program of the [appliedAI Institute for Europe](https://www.appliedai-institute.de/).

## Contents

- `missions/`: the missions in English, grouped by topic. `missions/missions.yaml` lists each mission's ID and number.
- `translations/de/`: the German translations of the missions, in the same folder structure.
